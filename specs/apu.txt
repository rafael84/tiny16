tiny16 APU
==========


OVERVIEW
--------

The Audio Processing Unit (APU) generates sound through 4 independent channels.
Each channel can produce different waveforms at specified frequencies and volumes.

Channels:
- Channel 0: Square wave (melody/lead)
- Channel 1: Square wave (harmony/chords)
- Channel 2: Triangle wave (bass/sub-bass)
- Channel 3: Noise (percussion/effects)

Sample Rate: 44,100 Hz
Output: 32-bit float mono
All channels mix equally with automatic volume normalization


CHANNELS
--------

Square Wave Channels (0, 1):
- Frequency range: 20 Hz - 20,000 Hz
- Volume: 0-15 (4-bit)
- Duty cycle: 12.5%, 25%, 50%, 75%
- Harmonics: Odd harmonics (1, 3, 5, 7...)
- Use: Melody, harmony, leads

Triangle Wave Channel (2):
- Frequency range: 20 Hz - 20,000 Hz
- Volume: 0-15 (4-bit)
- No duty cycle (fixed triangle shape)
- Harmonics: Odd harmonics with rapid falloff
- Use: Bass, sub-bass, mellow tones

Noise Channel (3):
- Period: 0-15 (affects noise "color")
- Volume: 0-15 (4-bit)
- Mode: Short (metallic) or Long (hissy)
- No frequency (generates pseudo-random noise)
- Use: Drums, explosions, percussion, wind, effects


MMIO REGISTERS
--------------

APU Control (0xBF40-0xBF5F):

0xBF40 : APU_CTRL         (RW) Master APU control
                               bit 0: APU enable (1=on, 0=off)
                               bits 1-3: reserved
                               bits 4-7: master volume (0-15)

Channel 0 (Square Wave 1):
0xBF41 : APU_CH0_FREQ_LOW  (W ) Frequency low byte
0xBF42 : APU_CH0_FREQ_HIGH (W ) Frequency high byte (11-bit total, 0-2047)
0xBF43 : APU_CH0_CTRL      (RW) Channel control
                               bits 0-3: volume (0-15)
                               bits 4-5: duty cycle (00=12.5%, 01=25%, 10=50%, 11=75%)
                               bit 6: reserved
                               bit 7: channel enable (1=on, 0=off)

Channel 1 (Square Wave 2):
0xBF44 : APU_CH1_FREQ_LOW  (W ) Frequency low byte
0xBF45 : APU_CH1_FREQ_HIGH (W ) Frequency high byte (11-bit total, 0-2047)
0xBF46 : APU_CH1_CTRL      (RW) Channel control (same format as CH0)

Channel 2 (Triangle Wave):
0xBF47 : APU_CH2_FREQ_LOW  (W ) Frequency low byte
0xBF48 : APU_CH2_FREQ_HIGH (W ) Frequency high byte (11-bit total, 0-2047)
0xBF49 : APU_CH2_CTRL      (RW) Channel control
                               bits 0-3: volume (0-15)
                               bits 4-6: reserved
                               bit 7: channel enable (1=on, 0=off)

Channel 3 (Noise):
0xBF4A : APU_CH3_PERIOD    (W ) Noise period (0-15, lower = higher pitch)
0xBF4B : APU_CH3_CTRL      (RW) Channel control
                               bits 0-3: volume (0-15)
                               bits 4-6: reserved
                               bit 7: channel enable (1=on, 0=off)
0xBF4C : APU_CH3_MODE      (W ) Noise mode
                               bit 0: mode (0=long, 1=short)
                               bits 1-7: reserved

Reserved for future:
0xBF4D-0xBF5F : Reserved (envelopes, sweep, etc.)


FREQUENCY
---------

The 11-bit frequency value (0-2047) represents a divisor that controls the pitch.

Calculation:
  actual_frequency_hz = 44100 / (16 * (2048 - freq_value))

Or inversely:
  freq_value = 2048 - (44100 / (16 * desired_hz))

Examples:
  freq_value = 1953  →  440 Hz (A4 note)
  freq_value = 1905  →  261 Hz (C4 note)
  freq_value = 1977  →  523 Hz (C5 note)
  freq_value = 2000  →  919 Hz
  freq_value = 1500  → ~80 Hz (bass)

Note: Higher freq_value = higher pitch
      Lower freq_value = lower pitch

WAVEFORMS
---------

Square Wave:
  Duty cycle controls the ratio of high to low:
    12.5% (00): ▀▃▃▃▃▃▃▃  Thin pulse, hollow sound
    25%   (01): ▀▀▃▃▃▃▃▃  Classic NES sound
    50%   (10): ▀▀▀▀▃▃▃▃  Perfect square, brightest
    75%   (11): ▀▀▀▀▀▀▃▃  Wide pulse, thick sound
  
  Harmonics: Contains only odd harmonics (1, 3, 5, 7...)
  Character: Bright, buzzy, classic 8-bit game sound

Triangle Wave:
  Shape: /\/\/\/\
  
  Harmonics: Odd harmonics with rapid falloff
  Character: Smooth, mellow, good for bass
  No duty cycle adjustment

Noise:
  Generated by Linear Feedback Shift Register (LFSR)
  
  Long mode (bit 0 = 0):
    15-bit LFSR, sounds hissy/white noise
    Use: Wind, ocean, static
  
  Short mode (bit 0 = 1):
    7-bit LFSR, sounds metallic/buzzy
    Use: Snare, hi-hat, explosions
  
  Period (0-15) controls noise "pitch":
    0  = Highest frequency (bright)
    15 = Lowest frequency (rumble)


MIXING
------

All enabled channels are mixed equally:
  
  final_sample = (ch0 + ch1 + ch2 + ch3) / active_channel_count
  final_sample = clamp(final_sample * master_volume, -1.0, 1.0)

Master volume (0-15):
  0  = Silent
  15 = Maximum (no attenuation)
  
Volume is applied linearly:
  volume_multiplier = volume / 15.0

Channels mix additively, then divide by active count to prevent clipping.


SYNCHRONIZATION
---------------

The APU operates independently from the CPU and PPU, generating audio continuously:

CPU/PPU Model:
- CPU: Executes instructions sequentially, one per tick
- PPU: Renders frame when triggered (RENDER_NOW bit at 0xBF30)
- Both are synchronous with program execution

APU Model:
- Audio callback runs asynchronously on separate thread
- Generates samples continuously at 44,100 Hz
- Reads APU MMIO registers to determine what to play
- No explicit "render" or "update" command needed

How It Works:

1. CPU writes to APU registers (0xBF40-0xBF5F):
   
   LOADI R0, 0x8C      ; Enable channel, set volume
   LOADI R6, 0xBF
   LOADI R7, 0x43
   STORE R0, [R6:R7]   ; CPU writes to APU_CH0_CTRL
   
2. Audio thread continuously reads APU state:
   
   - Samples are generated 44,100 times per second
   - Each sample generation reads current register values
   - If channel enabled → generate waveform at current frequency
   - If channel disabled → output silence
   
3. Changes take effect immediately:
   
   - When CPU writes new frequency → next sample uses new frequency
   - When CPU enables channel → audio starts immediately
   - When CPU disables channel → audio stops immediately
   - No buffering delay or sync required

Timing Relationship:

  CPU speed: ~60,000 instructions/second (1000 per frame at 60 FPS)
  APU speed: 44,100 samples/second
  Frame rate: 60 frames/second
  
  Samples per frame: 44100 / 60 = 735 samples
  Instructions per sample: 60000 / 44100 ≈ 1.36 instructions
  
  This means:
  - Audio updates are very frequent (every ~1.36 CPU instructions)
  - CPU register writes are reflected in audio almost instantly
  - No need to sync audio to frame boundaries

Comparison to PPU:

  PPU (Synchronous):
  - CPU writes to tile data, OAM, tilemap
  - CPU writes RENDER_NOW bit to 0xBF30
  - PPU reads data and renders frame
  - Result appears in framebuffer
  - Explicit trigger required
  
  APU (Asynchronous):
  - CPU writes to frequency, volume registers
  - Audio thread continuously generates samples
  - Changes reflected in next sample (~0.02ms later)
  - Audio output streams continuously
  - No explicit trigger needed

Practical Implications:

1. No "audio frame" concept:
   - Audio is continuous, not frame-based
   - Don't need to sync audio updates to 60 FPS
   - Can change notes mid-frame without glitches
   
2. Thread safety (implementation detail):
   - CPU writes to registers (producer)
   - Audio thread reads registers (consumer)
   - Simple lock-free reads work fine
   - Writes are atomic (single byte)
   
3. No audio buffer overflow:
   - Audio system requests samples as needed
   - APU generates exactly what's requested
   - No manual buffer management required
   
4. Timing audio events:
   - Use frame counter (0xBF22) for note timing
   - CPU controls when notes start/stop
   - Audio system handles sample generation
   
Example - Playing note for 30 frames:

    play_note:
        ; Start note
        LOADI R6, 0xBF
        LOADI R7, 0x43
        LOADI R0, 0x8C      ; Enable + volume
        STORE R0, [R6:R7]   ; Audio starts immediately
        
        ; Wait 30 frames
        LOADI R1, 30
    wait_loop:
        CALL  wait_frame    ; Wait for frame counter to increment
        DEC   R1
        JNZ   wait_loop
        
        ; Stop note
        LOADI R0, 0x00      ; Disable channel
        STORE R0, [R6:R7]   ; Audio stops immediately
        RET

The audio continues playing the entire time between enable and disable.
The CPU only needs to set the initial state - the audio thread does the rest.

Memory Safety:

  All APU state is in MMIO registers (0xBF40-0xBF5F)
  - CPU writes via STORE instruction
  - Audio thread reads via memory interface
  - No shared data structures
  - No race conditions with single-byte writes
  
  Atomic operations (guaranteed safe):
  - Writing volume byte
  - Writing frequency byte
  - Writing control byte
  - Enabling/disabling channel
  
  Non-atomic operations (CPU must handle):
  - Writing 11-bit frequency (2 bytes: low then high)
    Solution: Set volume to 0, update frequency, restore volume
    Or: Disable channel, update frequency, re-enable
  
  Example - safe frequency change:
  
    change_freq:
        ; Method 1: Disable during change
        LOADI R6, 0xBF
        LOADI R7, 0x43
        LOADI R0, 0x00      ; Disable
        STORE R0, [R6:R7]
        
        ; Update frequency
        LOADI R7, 0x41
        LOADI R0, 0x4C      ; New freq low
        STORE R0, [R6:R7]
        LOADI R7, 0x42
        LOADI R0, 0x07      ; New freq high
        STORE R0, [R6:R7]
        
        ; Re-enable
        LOADI R7, 0x43
        LOADI R0, 0x8C      ; Enable + volume
        STORE R0, [R6:R7]
        RET

Summary:

- APU runs continuously, asynchronously
- CPU controls APU via MMIO writes
- Changes take effect within ~0.02ms (1 sample period)
- No explicit sync or update command needed
- Audio generation is automatic and continuous
- Use frame counter for timing musical events


SOUND EFFECTS
-------------

Common patterns using the APU:

Explosion:
  1. Enable noise channel (CH3) at high volume
  2. Set period to ~8 (mid-range)
  3. Gradually decrease volume over 30-60 frames
  4. Optionally sweep period down for rumble effect
  5. Disable channel when volume reaches 0

Laser/Pew:
  1. Enable square channel (CH0) at medium volume
  2. Start at high frequency (1900+)
  3. Rapidly sweep frequency down (subtract 5-10 per frame)
  4. Duration: 10-20 frames
  5. Disable when frequency reaches target

Hit/Impact:
  1. Enable noise channel at max volume
  2. Short mode, period 4-8
  3. Duration: 3-5 frames (very short)
  4. Fast volume decay
  
Drum/Kick:
  1. Enable noise (CH3) at medium volume, period 2-4
  2. Enable triangle (CH2) at high volume, low frequency (80-120 Hz)
  3. Both: fast decay over 5-10 frames
  4. Noise provides "snap", triangle provides "thump"

Jump:
  1. Enable square channel
  2. Start at low frequency (1700)
  3. Sweep up to high frequency (1900) over 8 frames
  4. Short duration with quick volume fade

Coin/Item:
  1. Play sequence of notes rapidly:
     - E5 (3 frames)
     - G5 (3 frames)
     - C6 (6 frames)
  2. Use square wave with 50% duty
  3. Medium-high volume


TIMING
------

Frame rate: 60 Hz (typical)
Frames per second = 60

Common note durations (at 60 FPS):
  Whole note    = 120 frames (2.0 seconds)
  Half note     = 60 frames  (1.0 second)
  Quarter note  = 30 frames  (0.5 seconds)
  Eighth note   = 15 frames  (0.25 seconds)
  Sixteenth     = 7-8 frames (0.125 seconds)

Tempo in BPM (Beats Per Minute):
  60 BPM  = 60 frames per beat (1 second)
  120 BPM = 30 frames per beat (0.5 seconds)
  140 BPM = 25-26 frames per beat


EXAMPLES
--------

Play note A4 (440 Hz) on channel 0:

        ; Set frequency (freq_value = 1868)
        LOADI R6, 0xBF
        LOADI R7, 0x41
        LOADI R0, 0x4C      ; Low byte (1868 & 0xFF = 76 = 0x4C)
        STORE R0, [R6:R7]
        
        LOADI R7, 0x42
        LOADI R0, 0x07      ; High byte (1868 >> 8 = 7)
        STORE R0, [R6:R7]
        
        ; Enable channel: volume=12, duty=50%, enable=1
        LOADI R7, 0x43
        LOADI R0, 0xAC      ; 10101100: enable=1, duty=10, vol=1100
        STORE R0, [R6:R7]


Enable APU with master volume:

        LOADI R6, 0xBF
        LOADI R7, 0x40
        LOADI R0, 0xF1      ; Enable APU + master volume 15
        STORE R0, [R6:R7]


Play simple melody (C4-E4-G4):

    melody:
        ; Play C4 (261 Hz, freq=1768=0x06E8)
        CALL  note_c4
        LOADI R0, 30        ; Duration: 30 frames
        CALL  wait_frames
        
        ; Play E4 (330 Hz, freq=1819=0x071B)
        CALL  note_e4
        LOADI R0, 30
        CALL  wait_frames
        
        ; Play G4 (392 Hz, freq=1850=0x073A)
        CALL  note_g4
        LOADI R0, 60        ; Longer note
        CALL  wait_frames
        
        ; Silence
        CALL  silence
        RET
    
    note_c4:
        LOADI R6, 0xBF
        LOADI R7, 0x41
        LOADI R0, 0xE8      ; Low byte
        STORE R0, [R6:R7]
        LOADI R7, 0x42
        LOADI R0, 0x06      ; High byte
        STORE R0, [R6:R7]
        LOADI R7, 0x43
        LOADI R0, 0x8C      ; Enable, 50% duty, vol 12
        STORE R0, [R6:R7]
        RET
    
    note_e4:
        ; Similar pattern...
        RET
    
    note_g4:
        ; Similar pattern...
        RET
    
    silence:
        LOADI R6, 0xBF
        LOADI R7, 0x43
        LOADI R0, 0x00      ; Disable channel
        STORE R0, [R6:R7]
        RET
    
    wait_frames:
        ; Wait R0 frames using frame counter
        ; (Implementation depends on frame sync)
        RET


Explosion sound effect:

    explosion:
        ; Enable noise channel
        LOADI R6, 0xBF
        LOADI R7, 0x4A
        LOADI R0, 0x08      ; Period = 8 (mid rumble)
        STORE R0, [R6:R7]
        
        LOADI R7, 0x4B
        LOADI R0, 0x8F      ; Enable, volume 15 (max)
        STORE R0, [R6:R7]
        
        LOADI R7, 0x4C
        LOADI R0, 0x00      ; Long mode
        STORE R0, [R6:R7]
        
        ; Fade out over 60 frames
        LOADI R1, 15        ; Current volume
    explosion_loop:
        CALL  wait_frame    ; Wait 1 frame
        DEC   R1            ; Decrease volume
        JZ    explosion_end
        
        ; Update volume
        LOADI R7, 0x4B
        MOV   R0, R1
        OR    R0, 0x80      ; Keep enable bit set
        STORE R0, [R6:R7]
        
        JMP   explosion_loop
    
    explosion_end:
        ; Disable channel
        LOADI R7, 0x4B
        LOADI R0, 0x00
        STORE R0, [R6:R7]
        RET


Drum beat pattern:

    drum_beat:
        ; Kick drum (frames 0, 30)
        CALL  kick_drum
        LOADI R0, 30
        CALL  wait_frames
        
        CALL  kick_drum
        LOADI R0, 15
        CALL  wait_frames
        
        ; Snare (frame 45)
        CALL  snare_drum
        LOADI R0, 15
        CALL  wait_frames
        
        ; Loop
        JMP   drum_beat
    
    kick_drum:
        ; Noise + bass
        LOADI R6, 0xBF
        LOADI R7, 0x4A
        LOADI R0, 0x03      ; Low period
        STORE R0, [R6:R7]
        LOADI R7, 0x4B
        LOADI R0, 0x88      ; Enable, vol 8
        STORE R0, [R6:R7]
        
        ; Bass (80 Hz on triangle, freq≈1650)
        LOADI R7, 0x47
        LOADI R0, 0x72      ; Low byte
        STORE R0, [R6:R7]
        LOADI R7, 0x48
        LOADI R0, 0x06      ; High byte
        STORE R0, [R6:R7]
        LOADI R7, 0x49
        LOADI R0, 0x8D      ; Enable, vol 13
        STORE R0, [R6:R7]
        RET
    
    snare_drum:
        ; Short noise burst
        LOADI R6, 0xBF
        LOADI R7, 0x4A
        LOADI R0, 0x05      ; Mid period
        STORE R0, [R6:R7]
        LOADI R7, 0x4B
        LOADI R0, 0x8C      ; Enable, vol 12
        STORE R0, [R6:R7]
        LOADI R7, 0x4C
        LOADI R0, 0x01      ; Short mode (metallic)
        STORE R0, [R6:R7]
        RET


BEST PRACTICES
--------------

1. Initialize APU:
   - Enable APU master (0xBF40)
   - Set master volume to reasonable level (10-15)
   - Disable all channels initially

2. Note changes:
   - Always set frequency before enabling channel
   - Update frequency registers atomically (low then high)
   - Avoid glitches by setting volume to 0 before frequency changes

3. Sound effects:
   - Use dedicated channels for SFX vs music
   - Typical: CH0-1 for music, CH2-3 for effects
   - Keep effects short (< 1 second typically)

4. Silence:
   - Disable channel (bit 7 = 0) when not in use
   - Don't leave channels enabled at volume 0 (wastes CPU)

5. Volume management:
   - Use master volume for global fade in/out
   - Use channel volume for individual balance
   - Never exceed combined volume that causes clipping

6. Timing:
   - Use frame counter (0xBF22) for note timing
   - Align note changes to frame boundaries
   - Prefer frame-based timing over instruction counting


LIMITATIONS
-----------

- No envelope generator (ADSR must be manual)
- No frequency sweep (must be done per-frame in software)
- No PCM/sample playback (only synthesized waveforms)
- Limited polyphony (4 channels total)
- No stereo panning (mono output only)
- Fixed waveforms (cannot define custom waves)


RESET
-----

On reset:
- APU_CTRL = 0x00 (APU disabled, volume 0)
- All channel controls = 0x00 (disabled, volume 0)
- All frequency registers = 0x0000
- All other registers = 0x00
